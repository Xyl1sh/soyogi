# そよぎ
YouTube の URL から動画IDを取り出して、指定した中継先のアドレスに
組み立てるだけの道具です。VRChat の動画プレイヤー向け。
https://xyl1sh.github.io/soyogi/
## 特徴
- HTML 1枚。外部と一切通信しません
- 書体もアイコンも中に入っているので、オフラインでも動きます
- URL をまとめて貼れます。1行に1本
- 中継先の初期値が1つ入っています。設定欄でいつでも確認・変更・全消しできます
## 使う前に
中継サービスを通すと、その場に居合わせた全員の IP アドレスが
その運営者に渡ります。動画プレイヤーは URL をインスタンス内の
全員に同期するため、貼った本人だけの話ではありません。
VRChat が動画プレイヤーで無条件に信頼しているドメインは
youtube.com / youtu.be / googlevideo.com / topaz.chat などで、
中継サービスは含まれません。これは意図的な安全対策です。
素性の分かる相手かどうかを確かめた上でお使いください。
