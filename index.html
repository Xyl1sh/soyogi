決める前に、これだけ読んでください

中継先を通すと、その場に居合わせた全員のIPアドレスが、中継先の運営者に渡ります。 動画プレイヤーは URL をインスタンス内の全員に同期するため、貼った本人だけの話ではありません。視聴した一人ひとりの接続元が、相手側に記録されます。そしてその人たちは、この注意書きを読んでいません。 判断できるのは、貼るあなただけです。

VRChat は動画プレイヤーが無条件で信頼するドメインを公式に定めており、そこには youtube.com / youtu.be / googlevideo.com / topaz.chat などが並んでいます。中継サービスは含まれません。これは意図的な安全対策として設けられた仕組みです。VRChat では普段プレイヤー同士が互いの接続元を見られないため、ここは数少ない漏れ口にあたります。

転送先を握っているのは中継先の運営者です。 URL の見た目が変わらないまま、いつでも別の場所へ向け直せる立場にあります。素性の分かる相手かどうかを確かめてから使ってください。

また、公開インスタンスではワールド制作者が許可したホストしか通らないため、同じ URL でも見られる人と見られない人が出ます。

中継先を入れてください

このツールは中継先を持っていません。ご自身が使っている解決サービスのアドレスを入れてください。何を経由するかは、入れた方ご自身の選択になります。

転送を1つ足すごとに、IPアドレスを受け取る相手が1つ増えます。要らなければ空欄のままにしてください。

入れた内容はこのページの中だけに置かれます。保存も送信もしません。
